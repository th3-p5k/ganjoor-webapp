# دیوان گنجور (Ganjoor WebApp)

خوانشگاه و گنجینه آنلاین شعر کهن فارسی بر پایه پایگاه داده گنجور (`api.ganjoor.net`).

## ویژگی‌ها (Features)
- جستجو و مرور آثار بیش از ۲۴۰ شاعر نامدار پارسی‌گوی (حافظ، سعدی، مولانا، فردوسی، خیام، عطار، ...)
- تفأل و فال تصادفی از دیوان با پشتیبانی از فیلتر شاعر
- خوانش سنتی دوسطری / دومصرعی با قلم‌های استاندارد (وزیرمتن، امیری، نسخ، نستعلیق و لاله‌زار)
- ذخیره اشعار و یادداشت‌نویسی در دفاتر شعر شخصی (Offline / LocalStorage)
- اجرای ۱۰۰٪ مستقل و سازگار با **GitHub Pages** (Static HTML Export) بدون نیاز به سرور واسط

## اجرای محلی (Run Locally)

**پیش‌نیازها:** Node.js (نسخه ۲۰ به بالا) و npm

۱. نصب وابستگی‌ها:
```bash
npm install
```

۲. اجرای محیط توسعه:
```bash
npm run dev
```
سپس در مرورگر به آدرس `http://localhost:3000` بروید.

## خروجی و انتشار روی گیت‌هاب پیجز (GitHub Pages)

برای ساخت خروجی ایستا (Static HTML Export):

```bash
npm run build
```
یا با تعیین مسیر پروژه (Base Path):
```bash
NEXT_PUBLIC_BASE_PATH=/ganjoor-webapp npm run build
```
فایل‌های خروجی در دایرکتوری `out/` تولید می‌شوند.

اکشن خودکار GitHub Actions در مسیر `.github/workflows/deploy.yml` با هر پوش روی شاخه `main` به صورت خودکار پروژه را بیلد کرده و روی GitHub Pages منتشر می‌کند.
